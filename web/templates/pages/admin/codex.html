How to log in

  1. Add a session and click Login (device code).
  2. Open the link shown, sign in to ChatGPT, and enter the code. The status changes to ok by itself.
  3. Or import an existing ~/.codex/auth.json from a machine where you ran codex login.

Use a separate ChatGPT account per session. Copying one auth.json into two sessions can rotate its refresh token and log both out.
