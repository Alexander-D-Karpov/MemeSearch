How to log in

  1. Add a session and press Log in with device code.
  2. Open the link that appears, sign in to ChatGPT and enter the code. The status turns ok by itself.
  3. Or import ~/.codex/auth.json from a machine where you ran codex login.

Use one ChatGPT account per session. Importing the same auth.json into two sessions can rotate its refresh token and log both out. If login fails with 403, the server's region is blocked by OpenAI: set OPENAI_PROXY in .env and restart the ml and worker containers.
